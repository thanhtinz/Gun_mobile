# Defect inventory — subsystems audited against the PC dump

Produced by a 6-agent audit workflow (run `wf_a150ccb4-4ae`, 18 agents, 695 tool
calls, ~53 min) over the extracted Ok dump. Each agent reimplemented a shipped
reader's logic, ran it across every matching file in the dump beside an
implementation written from the format, and counted the disagreements — the same
method that found the eight bugs already fixed on this branch.

The dump is not in the repo (4.4GB; the archives are LFS pointers), so this file
is the record. `tools/audit_readers.py` re-derives the invariants behind the
fixes; this inventory is the list of what is still wrong.

**49 findings** (36 claimed to affect shipped behaviour), **65 checks
confirmed correct**. 12 findings went through an adversarial verifier —
10 upheld, 2 refuted.

> **Only 12 of the 36 live findings were verified.** The workflow capped
> verification at 2 per subsystem, leaving **24 unverified** (ui 12, physics 7,
> tables 3, packers 2). At the observed 2-in-12 refutation rate, expect some of
> those to be wrong. Verify before acting on anything not marked UPHELD.

### [LIVE — REFUTED] Every shipped ball has Weight=70, so the effective gravity is 0.49 px/frame² and the documented 0.7 constant is never used

- **Where:** `/home/user/Gun_mobile/UnityClient/Packages/com.gunmobile.port/Runtime/Logic/PcPhysics.cs:28`
